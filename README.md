# COMP1110_GroupC02_2026
This is group C02's project for the course COMP1110. The chosen topic is a smart pulic transport advisor.

**How to use?**
1. Run the main_menu.py file.
2. Add your desired network file to the folder containing the project. (A sample case "network.txt" already exists within the repo, if you want to use it).
3. Navigate the options menu by typing the name of the command or the number next to it


**FAQs**

_How to make a network file?_
Follow the format provided in the technical report, as there is a specific format and syntax to ensure the program accepts it.

_How do I customize my route?_
Go to the customize settings option, and start changing your preferences from there. Use the help tab to figure out what each option does
